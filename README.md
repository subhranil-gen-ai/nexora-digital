# NEXORA DIGITAL 🚀
### Creative Digital Agency Website

NEXORA DIGITAL is a modern, premium digital agency website designed to showcase creative digital solutions, website development services, UI/UX design, branding, and digital growth strategies.

The project focuses on delivering an elegant user experience through modern design, responsive layouts, smooth animations, and interactive components.

🌐 **Live Website:** https://nexora-digital-agenc-fs6q.bolt.host/

📂 **GitHub Repository:** https://github.com/subhranil-gen-ai/nexora-digital

---

## ✨ Features

- Premium and modern dark-themed UI.
- Fully responsive design for desktop, tablet, and mobile.
- Interactive navigation.
- Attractive hero section with call-to-action buttons.
- Agency introduction and services showcase.
- Portfolio section featuring illustrative concept projects.
- Step-by-step project workflow section.
- Contact form with client-side validation.
- Smooth animations and hover effects.
- Modern typography and gradient styling.

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/subhranil-gen-ai/nexora-digital.git
```

### 2. Navigate to the project directory

```bash
cd nexora-digital
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```

The development server will provide a local URL to preview the website.
